## 🚀 快速开始

**① 获取**

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

**② 打开**

双击 `迷枪图鉴-手枪.html`，或拖进浏览器。

**③ 手机上用**

把 HTML 文件发给自己，用手机浏览器打开即可。也可起个静态服务：

```bash
python3 -m http.server 8000
```

然后手机访问 `http://<电脑IP>:8000`。

<br>

> ✅ 无需 npm install、无需构建、无需联网。

## 🎮 功能特性

### 🔍 浏览

首页按型号分块，每块显示序号、品质分布彩条、皮肤款数。点击展开为**双列卡片网格**，点击卡片从底部弹出属性详情。「展开全部」可一次铺开全部型号。

### 🔎 搜索

支持 **皮肤名 / 型号名 / 系列名 / 属性名** 四维模糊匹配，实时响应。

搜属性是这个功能最实用的地方 —— 输入「射程」，所有带射程加成的皮肤一次列出，配装时比翻型号快得多。

筛选状态下页面自动切换为结果列表，并**只保留命中的型号板块**。

### 🎯 筛选

品质与属性各一个**自定义单选弹窗**，不是系统原生下拉：

- 选项左侧是真实品质色点
- 右侧胶囊显示该选项的条目数量
- 属性弹窗内置搜索框，40 项按出现频次排序

### 📋 详情

属性标签按品质色阶着色，红色标签（神兵）带辉光。一键「复制属性」，直接粘贴到聊天窗口。

### ✨ 视觉细节

| 效果 | 说明 |
| :--- | :--- |
| 🎨 **主题联动** | 选传说→橙金，选神兵→红，选稀有→蓝，全局渐变同步切换 |
| ⚡ **神兵特效** | 红色光点呼吸脉动 + 流光周期性扫过整行 |
| 🎬 **错帧动画** | 板块逐个上浮、卡片逐个弹入、属性标签逐条滑出 |
| 📳 **触感反馈** | 关键操作触发轻微振动（支持的设备） |
| 🌊 **水波纹** | 点击位置扩散涟漪，反馈明确 |
| 🌙 **深色模式** | 跟随系统自动切换 |

## 👆 交互说明

> [!IMPORTANT]
> 弹窗**没有关闭按钮**，只能通过手势关闭 —— 这是刻意的设计。

<table>
<tr>
<th width="30%">操作</th>
<th>效果</th>
</tr>
<tr>
<td><b>下拉横杠</b></td>
<td>按住顶部灰色横杠拖动，面板实时跟手；松手超过阈值关闭，否则回弹原位。按住时横杠变主题色并伸长</td>
</tr>
<tr>
<td><b>点击遮罩</b></td>
<td>点击弹窗外暗色区域立即关闭</td>
</tr>
<tr>
<td><b>滑动遮罩</b></td>
<td>在暗色区域向下滑动即可关闭</td>
</tr>
</table>

其他行为约定：

- 弹窗打开时**背景页面锁定滚动**，关闭后自动回到原位置，不会跳回顶部
- 列表滚到顶部或底部时**不会带动背景滚动**（滚动隔离）
- 结果超过 20 条显示「展开更多」，避免长列表糊屏
- 列表内容区不会误触发拖拽，只有顶部横杠与遮罩可拖动

## 📝 数据格式

### 文本格式

以 `手枪数据.txt` 为准，每行一条，字段用 ` | ` 分隔：

```
型号 | 子类 | 皮肤名 | 品质 | 属性1(颜色)、属性2(颜色)……
```

```text
USP | 手枪 | 兔美美 | 传说 | 提升武器射程(橙)、腰射子弹扩散减小(紫)、载弹量提升(蓝)
clock19 | 手枪 | USP（基础款） | 普通 | 无属性加成
```

颜色档位取 `红 / 橙 / 紫 / 蓝`，决定属性标签在网页中的显示颜色。

### 修改数据

直接编辑 HTML 中的 `const DATA = [...]` 数组：

```js
{
  m: "型号名",
  items: [
    {
      n: "皮肤名",
      q: "品质",              // 神兵 / 传说 / 史诗 / 稀有 / 普通
      s: ["系列"],            // 可留空数组
      a: [["属性文本", "#颜色值"]]
    }
  ]
}
```

## ⚙ 兼容性

| 项目 | 说明 |
| :--- | :--- |
| **浏览器** | 支持 CSS 自定义属性与 `:active` 的现代浏览器 |
| **系统** | iOS / Android / Windows / macOS |
| **屏幕** | 移动端优先，自适应至 520px 宽度 |
| **字体** | 标题与皮肤名使用行楷 |

字体栈：`STXingkai → 华文行楷 → Xingkai SC → 行楷 → STKaiti → 楷体`，品质与属性标签保持无衬线以保证小字号清晰。

> [!NOTE]
> iOS 与 Windows 通常预装行楷，显示正常。**多数安卓机型无预装行楷**，会回落到楷体或系统默认字体。若需全平台统一，可内嵌字体子集（仅打包页面用到的汉字，约 100–300KB）。
